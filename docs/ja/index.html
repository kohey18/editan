01 / 貼り付けるだけで、プレーンテキスト

まずは、文章だけに。

フォントも文字の色も、コピー元に合わせ直す必要はありません。いつもの ⌘V で、Editan の中にプレーンテキストとして展開されます。

Share with the team

→

Editan に貼り付けたあと ⌘ V

Next release
Small improvements. Big difference.
Polish the details
Share with the team

書式を持ち込まない流れを示す例です。Markdown の構文ハイライトは Editan 側の表示です。

もう少し詳しく

よくある質問。

貼り付けると、自動で Markdown に変換されますか？

貼り付けは、コピー元のテキストをプレーンテキストで取り込む操作です。Web ページの装飾やレイアウトを Markdown の記法に変換するものではありません。もともと含まれる Markdown の文字は、そのまま編集できます。

Claude は必須ですか？

いいえ。下書き、Markdown プレビュー、整形、定型文、コピーは Claude なしで使えます。AI 変換のみ、認証済みの新しい Claude Code CLI が必要です。利用枠や課金は CLI の設定に従います。

「Slack 用にコピー」で送信されますか？

送信はしません。Slack 向けのテキストをコピーして、ご自身で貼り付けます。リッチテキストのコピーも同様です。Notion 送信は、設定した連携と親ページを使って新しいページを作成します。

下書きと認証情報はどこに保存されますか？

下書きは ~/Library/Application Support/Editan/Buffers/ 内の Markdown ファイルです。Editan による暗号化は行いません。Notion トークンは macOS Keychain に保存します。旧形式からの移行に成功すると、以前の設定値を削除します。

Windows 版や Web 版はありますか？

現在は macOS 専用です。アプリの UI は日本語。このサイトは英語と日本語で利用できます。
